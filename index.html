The engine

More than a linter. A red-team analyst.

The in-browser scan catches the obvious patterns in seconds. Connect the deep-scan backend and the same findings run through dataflow analysis, cross-tool corroboration, and an automated verifier that removes false positives before a person ever reads them.

01

Dataflow taint analysis

Traces untrusted input through assignments and calls to dangerous sinks, so an injection is flagged only when attacker data can actually reach it — not on every risky-looking string.

02

Cross-tool corroboration

Bandit, pip-audit, and the taint engine each vote on a finding. Agreement raises confidence and severity; a lone noisy hit is demoted rather than paged out.

03

Variant analysis

Once a real weakness is confirmed, the engine sweeps the codebase for the same shape — the bug class, not just the single line you happened to open.

04

Automated verifier

A deterministic verifier re-checks each candidate against sanitizer and framework rules, labels likely false positives, and ranks what a human should read first.

05

Framework mapping

Every finding carries its CWE and the MITRE ATT&CK or ATLAS technique it enables, so a report lines up with the threat models your team already works from.

06

Authorized by design

Red Intelligence assesses and reports weaknesses. It does not run live exploits against third-party targets — every engagement is scope-gated and non-destructive.

Runtime safety

Agent Tripwire

Static analysis finds weaknesses before you ship. Agent Tripwire watches your AI agents after you ship — a synchronous monitor that inspects each tool call an agent is about to make and can hold, roll back, or kill it before it runs.

Pre-execChecks before execution. Shell, filesystem, and network calls are evaluated against policy before they run — not flagged after the damage is done.
<100msSynchronous control loop. Monitoring runs in-line, so a blocked action is stopped mid-flight rather than noted in a log no one reads.
CanaryTripwire tokens. Honeytokens seeded in context reveal prompt-injection and exfiltration attempts the instant an agent touches them.
